### Step 5: Create Anatomical Prefabs (20 min)

For each anatomical structure, create a prefab:

**Example: Creating ICA Prefab**

1. **GameObject → 3D Object → Cylinder** (for ICA vessel)
2. Scale: `(0.05, 0.5, 0.05)` (5mm diameter, appropriate for ICA)
3. **Create Material**:
   - Right-click in `Assets/Materials/AI_Generated/` → Create → Material
   - Name: `ICA_Material`
   - Shader: `Medical/SurgicalTissue`
   - Assign texture: `AI_Generated/ica_standard`
   - Set properties:
     - Wetness: 0.8
     - Blood Vessels: 0.5
     - Pulsation: 1.0 ⚠️
     - Subsurface Scattering: 0.6
4. Apply material to cylinder
5. Drag to `Assets/Prefabs/` to create prefab
6. Delete from scene

**Repeat for all structures**:
- `NasalSeptum` (Plane mesh)
- `NasalTurbinate` (Deformed sphere)
- `SphenoidSinus` (Cube mesh)
- `SellaTurcica` (Hemisphere mesh)
- `PituitaryAdenoma` (Irregular sphere with Perlin noise)
- `ICA_Left` (Tube/cylinder)
- `ICA_Right` (Tube/cylinder)
- `MWCS_Left` (Thin mesh membrane)
- `MWCS_Right` (Thin mesh membrane)

**💡 Tip**: For complex meshes (tumor, MWCS), consider exporting from the **web platform** (Three.js) using GLB/FBX export, then importing into Unity.

## 🐛 Troubleshooting

### "Shader compilation errors"
**Solution**: Ensure Universal RP package is installed and URP asset is set as Graphics quality setting.

### "Textures not loading"
**Solution**: Check textures are in `Assets/Resources/AI_Generated/` and named correctly (e.g., `ica_standard.png`, NOT `ica_standard_standard.png`).

### "Build fails with IL2CPP errors"
**Solution**:
1. Ensure NDK and JDK are installed
2. Edit → Preferences → External Tools → verify Android paths
3. Restart Unity Editor

### "Quest 3 not detected"
**Solution**:
1. Enable Developer Mode in Meta Quest mobile app
2. Connect via USB-C and approve USB debugging on Quest 3
3. Run `adb devices` in terminal to verify connection

### "Low FPS in VR"
**Solution**:
1. Reduce texture resolution to 1024x1024
2. Enable Dynamic Foveated Rendering
3. Reduce polygon count with LOD
4. Disable additional lights in shader
