## Key Optimization

BEFORE (Line 26 of EndoscopeRig.tsx):
  const intersections = raycaster.intersectObjects(scene.children, true);
  // Checks ~15 objects recursively
  // Complexity: O(n) where n = all scene objects

AFTER (Line 39-41 of EndoscopeRig.tsx):
  const intersections = collidableMeshes
    ? raycaster.intersectObjects(collidableMeshes, false)  // O(m)
    : raycaster.intersectObjects(scene.children, true);   // Fallback

  // Checks only ~3-8 anatomy meshes (non-recursive)
  // Complexity: O(m) where m = only collidable anatomy meshes
  // 80% fewer objects checked per raycast!
